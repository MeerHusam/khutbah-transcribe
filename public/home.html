How it Works
01 — Transcription

Arabic first

Audio is transcribed using Gemini 2.5 Flash, which handles dense Arabic speech well. Groq Whisper runs in parallel for word-level timestamps, over the whole file and again in short overlapping windows so no stretch of the audio is skipped. The outputs are aligned using Needleman-Wunsch sequence matching, so the final transcript carries Gemini's text with Whisper's real audio timing.

02 — Translation

Read as it was said

The transcript is split at breath-pause boundaries rather than fixed word counts. Claude translates each segment with the full khutbah in view, so the English reads as the imam intended rather than as a word-for-word substitution. Where the imam quotes a verse or a hadith mid-sentence, the published translation (Sahih International for verses, sunnah.com for hadith) replaces Claude's wording wherever it lines up.

03 — Quranic References

Nothing missed

Detection runs in three passes: Claude catches explicit citations ("قال الله تعالى"), a sliding-window scan finds ayahs cited without a signal phrase, and a 4-gram index catches partial recitations the other two miss. Each ayah is matched against the corpus and linked to quran.com. The full verse is shown with the recited part in bold, alongside the Sahih International translation.

04 — Hadith References

Linked to the source

Claude flags the hadith the imam quotes. The Arabic matn is searched on sunnah.com, preferring the collection the imam names ("رواه مسلم"), and a result is only accepted if its wording matches what was said. The link and narrator come from that sunnah.com page, so they are right regardless of numbering differences between hadith databases.

About

Meer Husamuddin

Software developer

LinkedIn · GitHub

I built KhutbahTranscribe because I wanted to understand the Friday Khutbah in full, not just follow along. The imam cites Quran and Hadith throughout; without knowing Arabic well, those references disappear into the sermon. This site is an attempt to surface them.

The pipeline uses speech recognition, large language models, and pattern matching against the Quran corpus and Hadith collections to produce a bilingual reader where every citation is identified, sourced, and linked.
